\cvsection{About Me}
\begin{cvparagraph}
    I've been writing software for about 10 years, and the last three I've spent as a Software Architect doing mostly backend and API work. I own four REST APIs that other teams and external partners build against, so a lot of my time goes to contracts, versioning, and the standards that keep them from breaking as they grow. I came up on the JVM: Java at Lockheed Martin, then several years of Gosu, which is close enough to Java that moving between them is mostly muscle memory. OO design and the usual design patterns are still how I reach for structure. I also like the less glamorous work, taking a brittle legacy component and rebuilding it into something reliable. I'm comfortable in AWS and Kubernetes and lean on Postgres, and I put real weight on tests and code review, since that's what lets a small team ship quickly without a mess of regressions.
\end{cvparagraph}
