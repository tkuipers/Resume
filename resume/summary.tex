\cvsection{About Me}

I've been writing software for about 10 years, with the last three focused on backend architecture, distributed systems, and platform infrastructure. I own the technical architecture for a platform managing \$300M ARR: 4 production REST APIs, a self-service developer platform I built solo (60x provisioning improvement, adopted by 3 teams), and multiple AWS-native services on Kubernetes running at 99.9\% uptime. I take these things from design through delivery and stay responsible for them. Technical leadership runs alongside the IC work: I'm on the Architecture Steering Committee, I've authored RFCs on development practices and system architecture, and I set technical direction for a 12-person team through code reviews, PR standards, and design guidelines. The work I find most satisfying is the kind that makes other engineers faster or lowers the cost of getting things wrong.
